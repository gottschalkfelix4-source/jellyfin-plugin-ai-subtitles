KI-Untertitel-Übersetzer

Übersetzt vorhandene Text-Untertitel (SRT, ASS, WebVTT, eingebettet oder extern) live im Web-Player in eine beliebige Sprache.

KI-Anbieter

Aus der Claude Console (console.anthropic.com → API Keys).
claude-opus-5-5 liefert die beste Qualität. claude-haiku-5-5 ist deutlich günstiger und schneller und für Untertitel meist ausreichend.
Wie gründlich das Modell nachdenkt. Für Untertitel reicht „low“; höhere Stufen kosten mehr Zeit und Tokens.
Standard: https://api.anthropic.com – nur für einen Proxy oder ein Gateway ändern.
Lehnt das Modell einen Abschnitt aus Richtlinien-Gründen ab, versucht die API automatisch ein Ersatzmodell (Beta-Funktion). Bei Proxys, die das nicht kennen, ausschalten.
Bis einschließlich /v1, z. B. https://api.openai.com/v1, http://ollama:11434/v1, http://192.168.1.10:1234/v1 (LM Studio), https://openrouter.ai/api/v1
Für lokale Server meist leer lassen.
Leer lassen, wenn das Modell keine Temperatur akzeptiert (z. B. Reasoning-Modelle).
Ausschalten, falls der Server den Parameter ablehnt.

                    

                


                

                    
Übersetzung

                    

                        
                        
                    

                    

                        
                        
                        
Zusätzlich kann im Player jede beliebige Sprache frei eingegeben werden.

                    

                    

                        
                        
                        
Zum Beispiel: „Duzen statt siezen“ oder „Fachbegriffe aus Star Trek nach der deutschen Synchronfassung übersetzen“.

                    

                    

                        
                        
                        
Kleiner = schnellerer Start, größer = weniger Anfragen. Standard 40.

                    

                    

                        
                        
                        
Wie viele vorherige Zeilen als Kontext mitgeschickt werden.

                    

                    

                        
                        
                    

                    

                        
                        
                    

                


                

                    
Einbindung

                    

                        
                        
Gilt für den Browser und die Apps, die die Server-Oberfläche verwenden (Jellyfin Media Player, Android-App). Nach dem Umschalten die Seite neu laden.

                    

                    

                        
                        
Die Übersetzung erscheint als Suchergebnis und wird beim Herunterladen dauerhaft gespeichert. Der automatische Untertitel-Download des Servers wird dabei bewusst übergangen, damit nicht ungewollt ganze Bibliotheken übersetzt werden.

                    

                    

                        
                    

                


                

                    
Alle Apps (TV, Handy, Apple TV …)

                    
Die Übersetzung erscheint in jeder Jellyfin-App als normale Untertitelspur, z. B. „Deutsch (KI)“ – auch auf Samsung/LG-Fernsehern, Android TV, Apple TV, iPhone und Roku. Die Apps laden eine Spur immer am Stück: Beim ersten Mal erscheinen die Untertitel daher erst, wenn der ganze Film übersetzt ist (je nach Modell etwa 1–5 Minuten). Danach kommt die Spur sofort aus dem Cache.

                    

                        
                        
Die Spur wird nur für Titel angeboten, die Text-Untertitel haben und noch keine Spur in der jeweiligen Sprache. Übersetzt (und bezahlt) wird erst, wenn jemand die Spur auswählt.

                    

                    

                        
                        
Die Reihenfolge nicht nachträglich umstellen, sonst ändern sich die Spurnummern laufender Wiedergaben.

                    

                    

                        
                        
Würde Jellyfin Untertitel in einer anderen Sprache einschalten als der bevorzugten Untertitelsprache des Benutzers (Benutzereinstellungen → Wiedergabe), wird stattdessen die Übersetzung gewählt.

                    

                    

                        
                        
Ist eine Folge fertig übersetzt, wird die nächste Folge der Serie im Hintergrund übersetzt, damit ihre Untertitel sofort da sind.

                    

                    

                        
                        
Der Browser hat den Übersetzen-Button mit Live-Übersetzung; die zusätzlichen Spuren sind dort meist nicht nötig.
